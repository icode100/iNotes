iNotes 1.0.0 is the first stable release for Apple silicon Macs.

- Centered paper when zoomed out, with text and handwriting kept on the same page.
- Full-page writing mode hides both navigation panes and the sheet heading. A separate toggle hides drawing tools, with controls to restore them. Shortcuts: Command–Shift–F and Command–Shift–T.
- Solid, dashed, and dotted straight lines with adjustable nib width.
- Center-divider templates for every paper style; left margins for plain and ruled paper. Template lines support solid, dashed, and dotted patterns.
- App-wide page colors: follow light/dark appearance or use off-white vintage paper. Switching palettes preserves note content and original ink colors.
- Classic, Alpine, Coast, and Forest workspace themes, drawn natively for light and dark appearances without large image assets.
- Stronger validation for imported and pasted handwriting, safe handling of empty strokes, and bounded native page rendering.
- Existing notebooks, automatic folder backups, equations, selection tools, and the pen cursor fix are retained.

Download the ARM64 DMG, open it, and drag iNotes to Applications. Updates are authenticated with the project's Ed25519 key.

This release is ad hoc signed and is not Apple notarized. On first launch of a downloaded copy, macOS may require **System Settings → Privacy & Security → Open Anyway**. Developer ID signing requires an Apple Developer Program membership.

The Mac release requires macOS 14 or later. iPad source and simulator validation are included in the repository; this DMG installs the Mac app only. Physical Apple Pencil pressure, tilt, and palm rejection still require device testing.
