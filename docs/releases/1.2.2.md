iNotes v1.2.2 candidate / prospective build 2020

This candidate carries the v1.2 changes below and the owned native Mac heading
controls validated in 1.2.1. It corrects the diagnostic's fixed settling-delay
assumption using bounded passive native-completion/callback observation. Existing
geometry thresholds and early motion evidence remain required; it does not
introduce a speculative production pane change. Fresh exact-source Native checks,
signed release checks and independent public-asset verification are pending.
Fresh release run **18** would produce build **2020**, subject to a live gate.

- **Matching paper:** page colors now follow the scenery and appearance, including maroon-black paper for dark Ruby Hills. Classic keeps its existing paper colors.
- **More papers:** Vintage White, Vintage Black, Pitch Black, Pitch White, and pastel Peach, Rose, Lavender, Mint and Sky. Explicit paper choices stay fixed across scenery and appearance changes; pitch papers use grey dots, rules and grids.
- **More ink colors:** sixteen named presets and a native custom color picker. Existing ink keeps its canonical saved colors; dark papers adapt their display for readability.
- **Blank pages first:** New sheet creates immediately without a naming dialog. Type into the underlined title area at the top to name the sheet; clearing it leaves the stored title blank. Sheet numbers and creation dates remain separate.
- **Page zoom:** Mac pages initially fit the visible editor width. Command-Plus (or Command-Equals) and Command-Minus zoom in 20% steps within 25–400%; View → Fit Page Width restores automatic fitting. Manual zoom survives theme and pane changes.

No notebook-format or dependency change. The user passed the initial isolated
1.2.0 QA app and authorized v1.2 publication on 5 November 2026. Later Mac heading
input changes passed native fixtures, without a new manual QA or physical IME
pass. Failed unpublished 1.2.0/build 2018 and 1.2.1/build 2019 remain reserved.
The latest verified public release remains **1.1.0 / build 2017**.
See [validation](https://github.com/icode100/iNotes/blob/main/docs/TESTING.md).

Requires Apple silicon and macOS 14+. Distribution remains ad hoc signed and
not Apple notarized. Physical stylus/iPad and cloud delivery need separate checks.
