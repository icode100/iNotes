iNotes 1.3.0 / build 2021

- Native rectangles, rounded rectangles, ellipses, triangles and diamonds.
- Straight or elbow connectors with no arrow, one arrow or arrows at both ends.
  Endpoints snap to shape/table anchors and follow moved or resized targets.
- Tables with selectable row/column counts and editable plain-text cells.
- Select and move objects with other page content; resize shapes/tables and drag
  connector endpoints. Double-click with Select to edit a label or table cell.
- Shared undo/redo, bounded mixed clipboard payloads, search, save/reopen and
  combined PDF/PNG exports retain diagrams alongside text, ink, equations/images.
- iPad shows a native read-only diagram preview with a Mac-only editing notice.
- Shape placement and image/diagram paste return to Select automatically, ready
  to move/resize or deselect with a blank click. Choose an icon or press S to
  place another shape. The shape chooser uses icons with tooltips and checks.

Use the Shapes and tables palette, then drag on the page. The Mac shortcut is S
from page focus or Command-Option-S while editing text. Shapes use the selected
ink color, nib width and line pattern; the palette also offers tinted fills.

Archives containing diagrams use format 4. Formats 1–3 still open, and older
apps reject new format-4 archives safely. No web runtime or new dependency.
