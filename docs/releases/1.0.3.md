iNotes 1.0.3 improves navigation and makes writing-tool sizes easier to choose.

Build **2011** adds two security fixes while retaining the same visible version:

- Large imported notebook hierarchies use indexed folder membership, avoiding repeated ancestry searches that could stall the app.
- Attachment reads remain bounded even if a selected file grows or is replaced during import. The 10 MiB picker limit and 64 MiB archive limit remain separate; existing archived attachments stay compatible.

Build 2011 passed 78 unit tests (XCTest and the standalone runner), 260 native
editor checks, 399 workspace checks, iPad simulator compilation, store/backup
integration, mounted installer verification, and signed-update tamper tests.
The security regressions include a valid 49,127-node archive and changing files
that exceed the attachment limit. Cursor and navigation regression checks passed;
this is not a new physical tablet/Pencil test or dependency-CVE scan.

Use **iNotes → Check for Updates…** to update from build 2010. The version remains
1.0.3, while Sparkle recognizes the higher internal build. The new installer is
`iNotes-1.0.3-build2011-arm64.dmg`; the original installer and v1.0.3 tag are retained
for build 2010. The release entry links the exact source commit for build 2011.

- Showing or hiding the notebook sidebar realigns the heading, tools, and page immediately, without needing a page click.
- Switching sheets preserves hidden panes and full-page mode. Pane transitions animate smoothly and retain their previous widths.
- Pen, Pencil, and Straight Line offer Extra Fine **0.3 mm**, Fine **0.45 mm**, Medium **0.7 mm**, and Broad **1 mm** nominal nibs.
- Brush/Marker offers Extra Fine **0.5 mm**, Fine **0.7 mm**, Medium **1 mm**, and Broad **1.5 mm** nominal nibs. Selecting a writing tool starts at Fine; existing notes and saved custom widths remain unchanged. Highlighter retains its earlier choices.
- Nib, paper, line style, template, appearance, page-color, and scenery menus visibly check the current selection.
- Earlier writing behavior and the existing pen-dot and highlighter cursors are retained. The experimental pressure boost is not included.

Local validation passed 68 unit/integration tests, 260 native editor checks, 399 workspace checks, and 164 iPad simulator checks, plus equation, typing, shortcut, backup, installer, and update-signature checks. Live Mac checks confirmed the nib labels, Fine defaults, and visible menu checkmarks. These are local results; public-build verification is recorded separately in the repository's testing record.

The Mac build requires Apple silicon and macOS 14 or later. It is ad hoc signed and not Apple notarized; first launch of a downloaded copy may require System Settings → Privacy & Security → Open Anyway. Signed updates verify release authenticity and integrity; they do not replace Apple notarization.
