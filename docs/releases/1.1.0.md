iNotes v1.1 (1.1.0), build **2017** — 4 November 2026.

- New Arctic, Open Skyscape, Ruby Hills, and Nature workspace scenery uses the supplied original light and dark photographs. Coast, Alpine, and Classic remain available. Forest has been removed; existing Forest preferences now show Nature.
- **Extra Broad** follows Broad in the nib menu: **1.5 mm** for Pen, **1.3 mm** for Pencil and Straight Line, and **2 mm** for Brush/Marker. Selecting a writing tool still starts at Fine. Existing strokes and custom widths retain their saved values; Highlighter keeps its earlier choices.

This update keeps the existing numbering, mixed-page Select All, image/ink,
undo, cursor, pane layout, archive, and backup behavior. No notebook-format or
dependency change is required. Scenery remains independent of page colors.

Validation evidence and limits are recorded in [docs/TESTING.md](https://github.com/icode100/iNotes/blob/main/docs/TESTING.md).
Release validation covers core regressions, Mac packaging/native diagnostics,
installer integrity, update signatures, and iPad simulator compilation. The user
also completed local manual QA. No local computer control or interactive UI
automation was used.

Requires Apple silicon and macOS 14+. Distribution remains ad hoc signed and
not Apple notarized. Existing Ed25519 signatures authenticate released updates;
they do not replace notarization. Physical stylus/iPad and real cloud delivery
are not established by automated checks.
