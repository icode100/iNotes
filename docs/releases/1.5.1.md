iNotes 1.5.1

**Build 2030** keeps the last movement of a handwritten stroke when you lift the pen on Mac. Short flicks retain their shape, and a tap still makes a dot. Pages with lots of handwriting redraw faster as you write, and automatic saves run in the background.

**Build 2029** fixes the gap below page navigation when you make a Mac window narrower. The open bar now reaches the bottom edge even when the horizontal scrollbar fades. You can still drag the scrollbar to pan the page.

- **Make the floating toolbar yours.** Open **More page tools → Customize floating toolbar…** to choose which buttons appear around the bubble. On Mac, use **Shape fill and arrow style** to change a selected shape’s fill or edit a connector. You can also reach customization from **Appearance → Full-screen toolbar**.
- **Type in the color you choose.** Select the Text tool, choose **Yellow** or any preset or custom color, and type in the page body or a positioned text box. Highlight existing words to recolor them. The **Text size** menu offers 13 sizes from 10 to 72 pt and preserves bold and italic.
- **Recolor selected objects together.** Use Select or Lasso, then choose a color for the selection. On Mac this covers handwriting, text, shapes, tables, arrows, equations and images. Image tint keeps the original pixels. Choose **Remove image tint** to restore them or **Handwriting only** to change just the strokes. Undo restores a mixed selection in one step.

Update each device that opens the same notebook before using image tints, equation colors, diagram label formatting, or explicitly near-white text. These styles use notebook format 6, which iNotes 1.5.1 can read.

Choose **iNotes → Check for Updates…** to install the Apple silicon Mac release.
